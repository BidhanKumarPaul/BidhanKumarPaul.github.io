This repository powers my personal portfolio website — a single place where visitors can learn about me, browse my work, check out the services I offer, and get in touch, all through a fast, mobile-friendly interface.

## 🧩 Pages & Features

| Page | Description |
|---|---|
| 🏠 `index.html` | Landing page introducing me and my work |
| 🗂️ `portfolio-details.html` | Deep-dive into individual portfolio projects |
| 🛠️ `service-details.html` | Overview of the services I offer |
